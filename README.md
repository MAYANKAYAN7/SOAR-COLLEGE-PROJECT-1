# SOAR Incident Containment Engine

# Overview
A Security Orchestration, Automation and Response (SOAR) platform designed to automate alert ingestion, threat intelligence enrichment, incident response, and case management.

# Features
- Alert Ingestion
- IOC Extraction
- Threat Intelligence
- Automated Playbooks
- AWS Security Automation
- RBAC
- Incident Dashboard

# Tech Stack
- FastAPI
- Python
- PostgreSQL
- AWS
- Docker
- GitHub Actions
